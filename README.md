# Sadhana Clinic

Redesigned website for Sadhana Clinic (Mahalakshmipuram, Bengaluru) — a family healthcare practice founded in 2008 by Dr. R. T. Selvi Prakash.

Live at: https://sadhana-clinic.github.io/

## Pages
- `index.html` — Home
- `about.html` — About / clinic story, mission, values
- `services.html` — Services in detail
- `packages.html` — All 11 health check-up packages (searchable/filterable)
- `doctor.html` — Doctor profile
- `health-hub.html` — Patient health education
- `contact.html` — Contact info and appointment request form

## Structure
Static, no build step. Shared design system lives in `assets/style.css` and `assets/script.js`.
